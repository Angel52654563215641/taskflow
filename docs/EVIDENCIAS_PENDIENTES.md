# Evidencias por recopilar
1. Contenedores activos en Docker Desktop.
2. Salida de `docker compose ps`.
3. Interfaz web con tareas de prueba.
4. Operaciones de crear, editar y eliminar.
5. Logs de aplicación y base de datos.
6. Panel del host con el servicio desplegado.
7. URL pública y endpoint `/api/health`.
8. HTTPS y certificado válido.
9. Persistencia después de reiniciar.

Datos reales: proveedor, fecha, URL pública, hostname privado de PostgreSQL, puerto de aplicación, resultado de salud y fecha de verificación TLS.
